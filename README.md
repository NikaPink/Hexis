# Hexis

A gamified workout tracker for Android (strength training and running), themed around Greek mythology.

> Work in progress — this is my first Android project, built to learn Kotlin and Jetpack Compose.

## Features

- Create and list workout sessions
- Local storage with Room (sessions, exercises, sets)

### Planned

- Session detail screen with its exercises
- Sets tracking per exercise
- XP and levels
- Exploration map (GPS, fog of war)

## Tech stack

- Kotlin, Jetpack Compose (Material 3)
- Room (SQLite) + KSP
- Coroutines / Flow
- MVVM architecture

## Getting started

1. Clone the repository
2. Open it in Android Studio
3. Run the `app` configuration on an emulator or a device
